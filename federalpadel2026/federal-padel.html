🔥 Configuración de Firebase

Conectá la app con Firebase Realtime Database para sincronizar en tiempo real.

⚠️ Importante: Para usar esto necesitás crear un proyecto en Firebase Console y activar Realtime Database.
📖 Cómo obtener la configuración:
1. Andá a console.firebase.google.com
2. Creá un proyecto nuevo
3. Andá a Build → Realtime Database y creá la base
4. Andá a ⚙️ Configuración del proyecto → General
5. En Tus apps, clic en el icono de Web
6. Copiá el objeto firebaseConfig y pegalo arriba
7. Reglas de seguridad: andá a Realtime Database → Reglas y poné:
{"rules":{".read":true,".write":true}}
🖼️ Foto de Portada

Cambiá la imagen que aparece en la cabecera de la app.

🔗 Sincronización con Google Drive

Conectá la app con Google Sheets para backup y compartir resultados.

Paso 1: Descargá el archivo apps-script-federal-padel.js y copiá todo el código.
Paso 2: Creá una hoja de Google Sheets nueva.
Paso 3: Andá a Extensiones → Apps Script.
Paso 4: Borrá el código por defecto y pegá el código descargado.
Paso 5: Guardá (Ctrl+S) y dale nombre "FederalPadel".
Paso 6: Clic en Implementar → Nuevo implementación.
Paso 7: Tipo: Aplicación web | Ejecutar como: Yo | Acceso: Cualquiera.
Paso 8: Copiá la URL del Web App y pegala acá abajo ↓
